# Аудируемый сценарий

Общая команда создаётся вручную по docs/ios-shortcuts.md. Переменная личного кода в исходном шаблоне пуста; при импорте задаётся вопрос для ввода кода получателя. Это описание действий, не подписанный файл .shortcut. Вопрос импорта и очистку поля при повторной публикации необходимо проверить на реальном iPhone до распространения.

Вход: один файл или изображение из Share Sheet → multipart POST intake (file) → ошибка или rows/warnings/previewText → подтверждение выбором valuation/offer либо отмена → JSON POST resolve → ошибка или warnings/workbook → Base64 decode → Set Name → Quick Look/Share.
