# Исходник команды iPhone

В этом каталоге хранится неподписанный исходник общего шаблона; установочный подписанный файл находится в `sm-techno-web/public/shortcuts/sm-techno-stock.shortcut`. Вопрос импорта должен оставаться пустым и принимать одну персональную настройку `SMTECHNO1.<base64 UTF-8 JSON>` с полями `baseUrl` и `credential`. Не включайте в шаблон действующие адреса или коды.

SHA-256 входного файла: `222fa7570209cd7d0d2ad64e91f1aef06d57040df3b3a475d3a00365f4dcf0ed`; SHA-256 подписанного файла: `d7a3ab1ee81c81c9ec44080747de447838c6b5ed6d1f158feeda5a4a97683442`. Первый импорт и работа на настоящем iPhone ещё не проверены.

Сценарий: один файл из меню «Поделиться» → просмотр и выбор формата либо отмена → открытие Excel. Инструкция пользователя — в `docs/ios-shortcuts.md`. Личная настройка не предназначена для передачи; не пересылайте настроенную копию команды до проверки поведения на iPhone. Если настройка попала к посторонним, отзовите подключение.
