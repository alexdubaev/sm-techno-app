# Исходник команды iPhone

В этом каталоге хранится неподписанный исходник общего шаблона; он не является готовым установочным файлом. Вопрос импорта должен оставаться пустым и принимать одну персональную настройку `SMTECHNO1.<base64 UTF-8 JSON>` с полями `baseUrl` и `credential`. Не включайте в шаблон действующие адреса или коды.

Путь готового проверенного и подписанного файла: `sm-techno-web/public/shortcuts/sm-techno-stock.shortcut`. До получения и аудита настоящего подписанного файла переключатель доступности в `lib/stock-shortcut-setup.ts` должен оставаться выключенным. Подпись и поведение на настоящем iPhone пока не проверены.

Сценарий: один файл из меню «Поделиться» → intake → просмотр и выбор формата либо отмена → resolve → открытие Excel. Подробности подготовки исходника находятся рядом с ним; инструкция пользователя — в `docs/ios-shortcuts.md`.
