# Расценка таблиц без обязательных заголовков

В «Остатках → Расценка артикулов» можно загружать XLSX, XLS, CSV и TSV без переименования столбцов. Известные заголовки и простые списки в одном столбце читаются без модели. Для нестандартных таблиц текущий провайдер определяет только номера столбцов и границы строк; все значения читаются из исходных ячеек, включая ведущие нули и нулевое количество. Затем менеджер проверяет редактируемый список перед поиском остатков.

Если структуру нельзя уверенно определить или провайдер недоступен, форма показывает образец таблицы. Менеджер выбирает столбцы, первую и последнюю строки товаров; количество необязательно. Ненужный лист можно исключить. Изменять файл не требуется. Файл, образец и выбор не записываются в БД или историю.

## API

Существующий `POST /api/stock/valuation/intake` сохраняет контракт `{rows, warnings}` для команд телефонов и других клиентов; он также получает автоматическое определение нестандартных таблиц. Если нужен ручной выбор, возвращает безопасное сообщение HTTP400 с предложением открыть расценку в приложении.

Новый `POST /api/stock/valuation/table-intake` используется интерактивной формой для таблиц. Права, временная рабочая папка, ограничения загрузки и слот распознавания совпадают с существующим intake. Поля multipart:

- `file`: исходная таблица.
- `selection` (необязательно, JSON до20000 символов): `{fileSha256, sheets:[{sheetIndex, articleColumn, quantityColumn, firstRow, lastRow, skip?}]}`. Все индексы начинаются с1, границы строк включительные; `quantityColumn:null` означает отсутствие количества. Должна присутствовать настройка каждого непустого листа. `skip:true` — явное исключение листа менеджером.

При успехе ответ `{rows,warnings}`. Для ручного выбора — `{rows:[],warnings,tableSelection:{fileSha256,sheets,mappings}}`; `sheets` содержит номер, название, число столбцов, последнюю непустую строку и ограниченный образец строк. Клиент хранит файл только в текущем состоянии и повторно передаёт его с выбором. SHA256 проверяется по заново загруженному файлу: старый выбор к другому файлу не применяется. Никаких серверных идентификаторов сохранённых файлов или доступа к чужим загрузкам нет. Ответы `no-store`.

Действуют пределы25МиБ,10000 строк/200 столбцов на лист,100 листов,200000 символов и2000000 ячеек на файл, до1000 извлечённых позиций. Ячейки с формулами, ошибками, датами и логическими значениями в выбранных столбцах не исполняются и отклоняются; длинные числовые артикулы требуют текста. Неверное определение структуры моделью открывает ручной выбор, а не отключает проверки. Проверка запрещённых внешних связей выполняется до обращения к модели. Стандартные документы и извлечение реквизитов не меняют свои схемы: для определения столбцов используется внутренний флаг запроса articles.
