# Рабочий процесс frontend

Каноническая линия разработки — main, исходники — sm-techno-web. Каждая задача начинается от свежего origin/main в отдельной codex-ветке и worktree/клоне, проходит тесты и PR в main. Постоянной develop нет.

Команды: [README](../README.md), правила: [AGENTS](../AGENTS.md), интеграция/архив: [release-workflow](release-workflow.md).

Сборка и публикация — отдельные согласованные действия по точному SHA из main, не автоматическое продолжение merge. Sites и Vercel не используются и исключены из публикации; Git deployments отключены в обеих Vercel-конфигурациях. Их прежний статус и зеркала не блокируют merge/release. Оставшуюся цель (серверный или локальный контур), доступ и runtime SHA нужно подтвердить перед отдельной публикацией; проверка 2026-10-06 показала, что VPS `91.227.68.176` отклонил вход с доступными SSH-ключами.

[Фактический аудит контуров](deployment-source-of-truth.md). Старые планы в docs/superpowers — исторические, не инструкции для нового выпуска.
