# Единый источник кода фронтенда

## Что является актуальным

- Канонический исходный код интерфейса находится в `sm-techno-web` ветки `main` этого репозитория.
- Ветка `main` — единственный источник кода, из которого готовится production-выпуск.
- Репозиторий Sites не является местом разработки. Это техническое зеркало, которое Sites требует для публикации и которое обновляется только точной копией уже проверенного состояния `main`.

## Как вносить изменения

1. Для каждой новой доработки создать отдельную ветку от свежего `main`.
2. Выполнить изменения и проверки в этой ветке.
3. После проверки слить её в `main`.
4. Собрать `sm-techno-web` из `main` и опубликовать это точное состояние в Sites.

Не редактировать и не публиковать код из произвольной ветки или из рабочего каталога технического зеркала. Если версия не находится в `main`, она не считается готовой к публикации.
