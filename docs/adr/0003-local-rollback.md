# ADR 0003: Локальный возврат с сохранением текущих данных

## Контекст
Для локальной реализации требуется возможность вернуться к прежнему коду без потери данных, появившихся после обновления. Серверная работа поставлена на паузу.

## Решение
Сохранять точные локальные исходные состояния кода и отдельно проверять сохранение и совместимость текущих данных и файлов при возврате. Архив кода сам по себе не доказывает восстановление данных. Серверный перенос и выпуск требуют отдельного разрешения и процедуры.

## Почему
Возврат кода и восстановление данных решают разные задачи: старый код не должен молча заменять или удалять более новые данные.

## Последствия
Локальная точка возврата должна ссылаться на точные SHA и проверяемые копии файлов. Нельзя утверждать, что production rollback проверен, на основании локального архива кода.
