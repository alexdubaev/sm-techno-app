# Private document runtime

The optional `compose.document-runtime.yaml` overlay gives the backend a private Codex home and the converter socket; it never mounts the Docker socket. The pinned Codex archive is verified during the backend build. The broker uses the existing `codex-deploy` account and its Docker access; that account therefore has Docker daemon authority. Do not expose its socket or runtime directories to other users. The backend runs as UID 0 and the broker accepts only UID 0; the client requires broker UID 1000.

Before installing the unit, prepare `/srv/sm-techno-test/runtime/converter` as `codex-deploy` owned mode 0700, and its `socket` and `work` directories likewise. Prepare `/srv/sm-techno-test/runtime/document-codex` as a private directory accessible to the backend UID 0. Store only `DOCUMENT_ASSISTANT_CONVERTER_IMAGE=sha256:...` in `runtime/converter/broker.env`, owned by `codex-deploy` and mode 0600. The ID must reference the locally installed, verified converter image carrying label `org.sm-techno.document-converter=v1`. No credentials belong in this file. The socket parent is mounted read-only; backend writes are restricted to socket protocol requests. The service unit's working directory must refer to the deployed release directory containing `document_runtime`; update it for the selected release before installing.

Install only the supplied service unit after reviewing its paths and image configuration. Start it using systemd, verify its socket is owner-only and its service is healthy, then use `docker compose -f docker-compose.yml -f compose.document-runtime.yaml` for the selected deployment. Authenticate Codex in its separate private home through the approved operator procedure; do not log or copy credentials. Follow the deployment and rollback runbooks, including backups and separate authorization for the target environment. Stop the unit when the overlay is removed. The broker holds an exclusive lease and cleans only owned, regular files in its own marked job directories; suspicious trees are left untouched for operator inspection.
