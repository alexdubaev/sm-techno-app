# Команда iPhone: расценка списка

Этот документ описывает сборку команды в приложении «Команды». Готовая подписанная команда и ссылка iCloud здесь не опубликованы. Первый импорт, обработку файла из меню «Поделиться», показ предупреждений и открытие обеих таблиц необходимо проверить на настоящем iPhone. Перед передачей общей команды проверьте на устройстве, что личный код не вошёл в опубликованную копию.

## Подключение

1. Откройте приложение на своём аккаунте, раздел «Остатки» → «Команды iPhone». Введите название телефона и создайте подключение. Скопируйте показанный один раз код. Он отличается от пароля и действует только для двух маршрутов ниже.
2. В приложении «Команды» создайте команду, принимающую в меню «Поделиться» один файл или изображение. Для общей копии оставьте поле личного кода пустым и добавьте к нему вопрос импорта (Import Question); каждый получатель вводит свой код. Не помещайте код в URL, название, комментарий или общий источник.
3. Укажите базовый HTTPS-адрес своего приложения без завершающего `/`. Не используйте чужие адреса и не загружайте URL из входного файла.

## Действия команды

1. Получите единственный файл из входных данных команды. Если файла нет или их больше одного, покажите сообщение и завершите выполнение.
2. «Получить содержимое URL»: POST на `{baseURL}/api/shortcuts/stock/intake`. Заголовок `Authorization` равен `Shortcut ` и введённому персональному коду. Тип тела — форма, поле файла называется `file`; значение — полученный файл. Не записывайте код в адрес.
3. При HTTP-ошибке покажите безопасный текст из `detail` и завершите команду. Не повторяйте распознавание автоматически. Если действие iOS не возвращает статус, используйте обработку ошибки действия; не продолжайте разбор как успешного ответа.
4. Из JSON-ответа получите `rows`, `warnings` и `previewText`. Покажите список и предупреждения пользователю. Затем покажите меню: «Excel для расценки», «Excel по шаблону КП», «Отмена». Отмена завершает команду, не отправляя второй запрос.
5. При выборе формата отправьте POST на `{baseURL}/api/shortcuts/stock/resolve` с тем же заголовком `Authorization` и `Content-Type: application/json`. Тело — словарь `{"rows": <rows из первого ответа>, "format": "valuation"}` или `"offer"` для шаблона КП. Строки не подменяются ценами или остатками с телефона.
6. При HTTP-ошибке покажите `detail` и завершите выполнение до декодирования. Например, 401 означает недействительное подключение, 429 — повтор позже, 422 для шаблона КП — нет подходящих позиций. Автоматических повторов не делайте.
7. Из успешного ответа покажите все `warnings`. Получите `workbook.base64`, декодируйте Base64 в файл, действием «Задать имя» присвойте `workbook.filename`, откройте «Быстрый просмотр» (Quick Look) и при необходимости меню «Поделиться». `workbook.mediaType` — MIME-тип файла.

Отзыв выполняется в той же панели подключений; после него создайте новый код. После восстановления резервной копии все телефоны необходимо подключить заново. Обычный выход из одного сеанса браузера подключение телефона не отзывает.
