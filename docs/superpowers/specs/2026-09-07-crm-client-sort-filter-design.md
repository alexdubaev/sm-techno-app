# CRM: сортировка и фильтрация клиентов

## Цель

Добавить локальную сортировку и фильтры телефон/email во все CRM-вкладки desktop и mobile, не изменяя данные CRM, назначения, порядок в базе или 1С.

## Состояние и обработка

`CrmWorkspace` хранит `sortMode`, `phoneFilter` и `emailFilter` в состоянии текущего workspace. Они сохраняются при открытии карточки и возврате. Новые backend-методы, SQL-сортировки, endpoint'ы и кэш-схемы не добавляются.

Единый `useMemo` обрабатывает загруженный `clients` в порядке: текстовый поиск → текущий sync-status → телефон → email → сортировка. Наличие контакта определяется `value.trim().length > 0`.

Режимы сортировки:

- `manual` — исходный порядок массива;
- `name_asc`/`name_desc` — `documentName || name`, `localeCompare(..., "ru")`;
- `newest`/`oldest` — `createdAt`, равные значения стабильно разрешаются по `id`;
- `free_first`/`busy_first` — `workOwners.length === 0` / `> 0`, с сохранением исходного порядка внутри групп.

Автоматические режимы не пишут в `position`, preference или orderVersion. Возврат в `manual` немедленно показывает исходную пользовательскую расстановку.

## Поведение UI

Desktop получает компактные select «Сортировка», «Телефон» и «Почта» рядом с текущими инструментами. Mobile показывает одну кнопку «Фильтры и сортировка» и количество активных фильтров; sheet содержит все режимы, сегментированные телефон/email, reset и «Показать N клиентов».

Drag-and-drop разрешён только при `manual`, без поиска и без активных фильтров, как существующее правило; при автосортировке явно объясняется возврат к «Ручному порядку».

Если загруженная вкладка не пуста, но комбинация даёт ноль элементов, показывается «Клиенты не найдены» и действие «Сбросить фильтры». Reset возвращает manual/all/all и не меняет вкладку или текстовый поиск.

## Проверки

Тесты покрывают семь сортировок, телефон/email и их комбинации с поиском/workOwners, стабильность и восстановление ручного порядка, блокировку drag-and-drop, desktop controls, mobile sheet/apply/reset/indicator и filtered empty state.
