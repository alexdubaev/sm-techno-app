# Цена, карточка и остатки

В разделе «Работа с прайсом» строка товара относится к конкретному складу.
Цена в карточке относится к выбранному складу; если товар ещё не распределён
по складам, показывается базовая цена для нового остатка.

1. Выберите нужную строку товара и склада.
2. Измените цену или данные карточки, затем нажмите кнопку сохранения цены и данных.
   Другие склады и их остатки при этом не меняются.
3. Для прихода, перемещения или списания откройте панель складских операций.
   Выберите операцию, склад и количество, затем подтвердите её кнопкой внутри панели.
   Операция сохраняется сразу; повторное сохранение карточки для неё не требуется.

«Добавить остаток» **прибавляет** количество. Если уже есть 3 шт., а должно стать
5 шт., добавьте 2 шт. Для уменьшения используйте списание или перемещение.
Просмотр панели сам по себе ничего не сохраняет.

Несохранённая цена и текст карточки сохраняются в форме при открытии панели
и выполнении складской операции. После неё сохраните цену и данные отдельной
кнопкой. При переходе к другой позиции приложение предупреждает о несохранённых
изменениях. Ошибка сохранения оставляет введённые значения в форме.

Для разработчика: PATCH принимает optional `priceWarehouseId` и сохраняет цену
только указанного активного остатка в одной транзакции с данными карточки.
Без `warehouses` и `quantity` замена остатков не запускается. В targeted PATCH
эти поля запрещены. Старый явный полный список складов поддерживается;
пропущенная цена существующего склада сохраняется, новая строка получает
базовую цену. Нулевую цену отличаем от отсутствующего значения.
