# Передача списка в Остатки с Android

Установите сайт через меню Chrome «Установить приложение» и войдите в нужный аккаунт. В другом приложении выберите один файл или текст → «Поделиться» → СМ ТЕХНО. В Остатках проверьте выбранный источник и нажмите «Распознать», затем проверьте строки и остатки. Доступны оба прежних Excel. Можно также вставить список, выбрать фото или файл непосредственно в Остатках.

Передача временная и одноразовая, хранится только в памяти браузера до двух минут. Если браузер выгрузил её, сессия изменилась или появилось сообщение об ошибке, войдите в нужный аккаунт и отправьте заново либо выберите источник вручную. Название без содержимого и отдельная ссылка не распознаются. Сервисный worker не обслуживает остальные страницы и API и не сохраняет файлы в постоянное хранилище.

Доступность пункта в системном меню и импорт команды iPhone с именем «Поделиться СМ ТЕХНО» требуют проверки на физических устройствах; имя файла загрузки само по себе не подтверждает имя импортированной команды.
