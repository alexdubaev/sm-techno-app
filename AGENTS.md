# Правила веток и публикации

## Единственный источник истины

- `main` этого репозитория — единственная ветка с проверенным кодом.
- Каждая новая задача начинается в одной отдельной ветке `codex/<задача>` и
  отдельном worktree.
- Перед слиянием в `main` обязательны тесты и сборка, относящиеся к изменению.
- После успешной проверки ветка сливается в `main`; неиспользуемые ветки не
  удаляются без явного запроса пользователя.

## Публикация в Sites

- Исходники опубликованного сайта находятся в отдельном репозитории Sites. Его
  ветка `main` не синхронизируется с этим репозиторием автоматически.
- Для публикации сначала переносить в Sites ровно проверенные клиентские
  изменения из этого `main`, затем собирать, тестировать, коммитить и
  публиковать Sites-версию.
- В коммите Sites указывать исходный SHA из этого репозитория, чтобы можно было
  однозначно сопоставить опубликованную версию с `main`.
- Нельзя публиковать точечное исправление из Sites, если оно обходит актуальный
  проверенный `main`, без отдельного согласования с пользователем.
