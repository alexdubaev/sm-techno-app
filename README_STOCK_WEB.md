# Web version of 1C stock and order app

Это первый web-контур проекта СМ ТЕХНО на Streamlit. Он оставлен в репозитории как legacy-версия и может использоваться отдельно от нового Next.js интерфейса.

## Что уже есть

- общий вход пользователей приложения;
- роли `admin` и `manager`;
- личный профиль пользователя с логином 1С;
- пароль 1С хранится только в текущей сессии браузера;
- общий локальный каталог и остатки;
- создание заказов в 1С под личной учетной записью пользователя;
- административный раздел для импорта прайса и работы с локальным каталогом;
- системные настройки интеграции с 1С;
- управление пользователями приложения.

## Первый запуск

```powershell
cd D:\codex\sm-techno-app
.\.venv\Scripts\python.exe -m streamlit run web_stock_app.py
```

После первого запуска автоматически создается администратор:

- логин: `admin`
- пароль: `admin123`

## Что важно сейчас

- URL базы 1С и системные ключи задаются администратором;
- каждый пользователь указывает свой `логин 1С` в профиле;
- `пароль 1С` вводится заново на текущую сессию браузера;
- загрузка прайса доступна только администратору.

## Дальше можно улучшать

- переносить хранение из SQLite в Postgres только по отдельному плану;
- полностью выводить пользователей с legacy Streamlit на новый Next.js frontend;
- поддерживать репозиторий как источник общей бизнес-логики, пока legacy-контур еще нужен.
