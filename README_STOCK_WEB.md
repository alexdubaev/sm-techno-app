# Web version of 1C stock and order app

Это первый перенос desktop-логики в общую web-версию на Streamlit.

## Что уже есть

- общий вход пользователей приложения
- роли `admin` и `manager`
- личный профиль пользователя с логином 1С
- пароль 1С хранится только в текущей сессии браузера
- общие локальные остатки и каталог
- создание заказов в 1С под личной учеткой пользователя
- админский раздел для импорта прайса и работы с локальным каталогом
- системные настройки интеграции с 1С
- управление пользователями приложения

## Первый запуск

```powershell
cd D:\codex\SEO_Gen
.\.venv\Scripts\python.exe -m streamlit run web_stock_app.py
```

После первого запуска автоматически создается администратор:

- логин: `admin`
- пароль: `admin123`

## Что важно сейчас

- URL базы 1С и системные ключи задаются администратором
- каждый пользователь указывает свой `логин 1С` в профиле
- `пароль 1С` вводится заново на текущую сессию браузера
- загрузка прайса доступна только администратору
