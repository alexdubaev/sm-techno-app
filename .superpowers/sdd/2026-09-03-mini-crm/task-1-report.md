# Task 1 — отчёт

## Результат

Реализовано административное действие «Оставить только в основной вкладке» для связанной с 1С карточки клиента с активным личным назначением.

## Изменения

- Добавлен `removeCrmAssignment(clientId, ownerId?)`: `DELETE /api/crm/clients/${clientId}/assignment` с `ownerId`, через `requestJsonWithInit` и русским fallback-сообщением.
- В `ClientDetailDialog` действие доступно только администратору для карточки, связанной с 1С, с неархивированным личным назначением.
- Добавлено доступное `AlertDialog`-подтверждение: названы клиент и выбранный сотрудник, явно сказано о сохранении карточки в «Клиенты 1С», истории и напоминаний.
- Успех очищает назначение и preference в открытой карточке, обновляет аудит и список, показывает русское уведомление; ошибки выводятся существующим UI.
- В журнал добавлена метка `remove_assignment: «Оставлен только в основной вкладке»`.
- Исправлен пропущенный false-branch (`: null`) в существующем JSX-подтверждении архивирования; это устранило синтаксическую ошибку, выявленную TypeScript-проверкой.
