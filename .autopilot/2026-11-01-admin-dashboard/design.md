# Визуальное решение — дашборд администратора

Пользователь: руководитель СМ ТЕХНО. Главная задача экрана — понять продажи всей компании за выбранный период, вклад менеджеров и расход DeepSeek.

Сохраняется существующая оболочка, фирменные цвета и системный шрифт. Источник токенов — app/globals.css, элементы управления согласуются с manager.module.css. Новых шрифтов и зависимостей нет.

- Фон #f5f7fa, панели #ffffff, текст #0b1736, вторичный текст #6b7890, линии #e3e8f0, акцент #ffc400. Успешное выполнение — существующий #16a34a с текстовым значением.
- Заголовок 24px/700; названия блоков 17px/650; подписи и таблица 12–14px. Segoe UI Variable / Segoe UI / Arial. Для сумм и шкал tabular-nums, без декоративного шрифта.
- Сверху название «Обзор компании», общий переключатель Неделя / Месяц / Квартал / Год и переход по периодам. По умолчанию текущий месяц Москвы.
- Главная область: общая сумма продаж и её временной график, компактные дополнительные показатели без ряда одинаковых больших карточек. Одна ясная шкала времени; подписи рублей, удобные подсказки и текстовый доступ к значениям.
- Ниже все менеджеры: сумма, количество, план, выполнение при наличии. Исторические/неактивные явно отмечены. Связь с личным кабинетом менеджера использует существующие права.
- Отдельный спокойный блок DeepSeek: график расхода, число запросов, токены и баланс при доступности. Период учёта и неизвестные значения честно обозначены. Нулевые известные данные отличаются от отсутствия истории/ошибки.
- Отличительный элемент — полосы доли продаж в строках менеджеров, согласованные с общей суммой, позволяющие видеть вклад без круговой диаграммы и лишней декоративной анимации.
- На телефоне: переключатель 4 периода помещается в ширину, график выше списка, строки менеджеров превращаются в компактные карточки; DeepSeek ниже. Min-width:0, нет горизонтального скролла страницы. Управления от 44px, видимый focus, графики с доступными подписями.

Проверка решения: соответствует рабочему интерфейсу CRM, сохранились фирменные токены. Отказ от отдельной визуальной темы/героя: руководителю важны сопоставимые цифры. Состояния loading/error/empty независимы у продаж и DeepSeek. Конкретная семантика плана и лимитов будет зафиксирована после ответов владельца.
