- Архитектура и границы локальной расценки и документов: `docs/architecture.md`.
- Для продолжения текущей работы проверьте `.autopilot/PROGRESS.md`; историю изменения устанавливайте по Git-коммитам и PR, не считая рабочие заметки доказательством публикации.
- Изолированная демонстрация: `python scripts/local_workflows/run_demo.py` из отдельной подготовленной копии; скрипт использует синтетические данные и порты 15100/19100. Не направляйте её на рабочую базу, storage или 1С.
- Frontend: из `sm-techno-web` доступны `npm run test:auth`, `npm run test:settings`, `npm run lint:ci`, `npx tsc --noEmit --incremental false`, `npm run build` и изолированный `npm run test:auth:e2e`. `lint:ci` проверяет существующий baseline; это не означает чистый обычный `npm run lint`.
- Backend-проверки выполняйте в изолированном окружении: `python -m pytest tests/auth -q --strict-markers` и соответствующие затронутые тесты. Результат полного набора с отдельными исправлениями проверок нельзя представлять как один полностью зелёный запуск.
