# Границы, решённые в спецификации

- Тема — корневой html[data-ui-theme="glassy"], классика по умолчанию при отсутствующем атрибуте или значении classic. Предпочтение: локальный ключ sm-techno-ui-theme, допустимы "classic" и "glassy". Вёрстка и переключатель настроек используют общий источник, с безопасным доступом к localStorage и без серверного состояния.
- Тема применяется корневым стилем, в том числе к порталённому UI. Изолировать добавленные селекторы, переиспользовать существующие классы и переменные, добавлять семантические классы вместе с прежними. Десктопное боковое и мобильное нижнее меню используют существующие пути, группы, права и ссылки.
- Структура Обзора и Остатков меняется только для режима glassy там, где этого требуют макеты. Компоненты используют исходные данные и обработчики. Форматы валют и остатков действующие. Статусы склада не перекрашивать в чисто декоративные.
- Авторизационные границы, контракты, схема/миграции, рабочие параметры 1С, сторонние зависимости и релиз не меняются. Использовать синтетические данные, локальные скрипты запуска без рабочего окружения и разрешённый launcher для E2E.
- Проверки из sm-techno-web: npm run test:auth, npm run test:settings, npm run lint:ci, npx tsc --noEmit --incremental false, npm run build. Точечный браузерный путь через npm run test:auth:e2e с нужными фильтрами. Не понижать baseline, не менять ограничения launcher. Использовать имеющиеся зависимости проекта.
- Правила предыдущей работы с Обзором сохранены в carried.md: компактность, раскрытие графика, данные выбранного периода и отдельные месячные планы, единственное окно «Выписка» с историей, сохранение оболочки и всей навигации.
- Визуальные цели — созданные в чате четыре изображения. Код и макет сравниваются по каждому целевому экрану, с приоритетом доступности и рабочих элементов реального интерфейса.
