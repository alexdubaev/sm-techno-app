# SEO Generator for Product Cards

Приложение для массовой генерации SEO-данных по таблице товаров.

## Что делает

1. Загружает `XLSX/XLS/CSV` файл.
2. Автоматически находит колонки:
- `Артикул`
- `Наименование`
- `Бренд/Производитель`
3. Если наименование на английском, переводит на технический русский.
4. Если наименование пустое, делает поиск по `Бренд + Артикул` в интернете и сохраняет URL источников.
5. Генерирует:
- `Meta description`
- `Meta keywords`
- `Краткое SEO-описание`
- `Уникальное описание товара`

В офлайн-режиме (без API) SEO-описания строятся по `Артикулу + Бренду + найденным источникам` и не дублируют текст из колонки `Наименование`.

## Запуск

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Тестовый файл

В проект добавлен пример: `sample_input.csv`.
Его можно сразу загрузить в интерфейс для быстрой проверки пайплайна.

## Важные замечания

1. Для качественной генерации (перевод, SEO и описание на основе фактов) укажите `OpenAI API key` в интерфейсе.
2. Без API-ключа работает fallback-режим с шаблонными текстами.
3. Интернет-поиск не гарантирует 100% официальный источник для каждого бренда, но алгоритм старается ставить выше домены, похожие на сайт производителя, и понижает маркетплейсы.
